# King Fish — موقع تعريفي عالمي لمصنع تصدير الأسماك والمأكولات البحرية

## نظرة عامة
موقع تسويقي/تعريفي (Corporate Website) لعلامة **King Fish** لتصنيع وتصدير الأسماك والمأكولات البحرية الطازجة والمجمدة، مستوحى في محتواه التقني من تقرير تحليل مشروع **NileTrace Enterprise** (منصة B2B لتتبع سلسلة توريد الأسماك: الاستلام، التحويلات، المخزون، الشحن، سلسلة التبريد، ومعايير HACCP وسجل التدقيق). تم تحويل هذه المفاهيم التقنية إلى محتوى تسويقي مبسّط للزوار (قسم "الجودة والتتبع الرقمي").

> ملاحظة: تعذّر على أداة تحليل المستندات قراءة نص ملف الـ PDF بالكامل (فشلت المحاولات المتكررة)، لذا تم الاعتماد على المقتطف النصي الظاهر في بداية الملف (الملخص التنفيذي) لاستخلاص المصطلحات والمفاهيم الأساسية: التتبع، سلسلة التبريد، HACCP، المدفوعات، الاستلام، التحويلات، المخزون، الشحن، سجل التدقيق.

## الصفحات/الأقسام المُنفّذة (صفحة واحدة Single Page — index.html)
1. **Hero** — خلفية فيديو (الفيديو التعريفي المرفق `King_Fish_brand_introduction_video`) + عنوان رئيسي + إحصائيات متحركة (Counters).
2. **Marquee Strip** — شريط متحرك بالشهادات والمزايا (HACCP, ISO 22000, تتبع كامل...).
3. **About (من نحن)** — نبذة عن الشركة + نقاط تميز + صور حقيقية (مراكب صيد + تخزين مبرد).
4. **Process (رحلة الإنتاج)** — Timeline من 5 خطوات: الصيد → الاستلام والفرز → التصنيع والتعبئة → الشحن المبرد → التسليم.
5. **Facilities Gallery (داخل King Fish)** — معرض صور Bento/Mosaic بـ5 صور حقيقية: أسطول مراكب صيد في عرض البحر، صيادون يجمعون الشباك، غرف تخزين مبرّدة داخل المصنع، خط تجهيز وتصنيع الأسماك، أحزمة نقل وتعبئة أوتوماتيكية.
6. **Products (منتجاتنا)** — شبكة بطاقات: أسماك طازجة، جمبري وقشريات، منتجات مجمدة، تشكيلة فنادق ومطاعم.
7. **Quality & Traceability (الجودة والتتبع الرقمي)** — قسم داكن يعرض 3 محاور مستوحاة من تقرير NileTrace: تتبع كامل للسلسلة، سلسلة تبريد ذكية، معايير HACCP.
8. **Certifications (الشهادات)** — HACCP, ISO 22000, MSC, HALAL, EU Export.
9. **Global Reach (انتشارنا العالمي)** — قائمة مناطق التصدير + صورة شحن.
10. **Testimonials (آراء العملاء)** — 3 شهادات عملاء افتراضية.
11. **CTA Band** — دعوة لطلب عرض سعر.
12. **Contact (تواصل معنا)** — معلومات تواصل + نموذج طلب عرض سعر (تجريبي، بدون باك-إند حقيقي).
13. **Footer** — روابط سريعة، منتجات، نشرة بريدية.

## المزايا التقنية
- تصميم متجاوب بالكامل (Desktop / Mobile) مع قائمة هامبرغر للموبايل.
- دعم لغتين: **عربي (افتراضي RTL)** و **إنجليزي (LTR)** عبر زر تبديل لغة في الهيدر (ترجمة JS من القاموس في `js/main.js` دون إعادة تحميل الصفحة).
- فيديو خلفية Hero مع تشغيل تلقائي صامت متكرر (`autoplay muted loop playsinline`) وتبطيء سرعة العرض (0.75x) لإحساس فخامة أكثر.
- عدادات إحصائية متحركة عند التمرير (Intersection Observer).
- تأثيرات ظهور تدريجي (Reveal on Scroll) لجميع الأقسام.
- Font Awesome للأيقونات + خطوط Google (Poppins / Cairo).
- نموذج تواصل بتغذية راجعة فورية (واجهة أمامية فقط — غير متصل بقاعدة بيانات أو بريد فعلي حاليًا).

## الملفات
```

images/               شعار + صور مصنع/أسماك/جمبري/شحن (صور مرخصة CC/PD أو مولّدة بالذكاء الاصطناعي)
```

## مصادر الصور
- الشعار: تم توليده بالذكاء الاصطناعي خصيصًا لعلامة King Fish (نسختان: ملوّنة وأبيض/فاتحة).
- صور المصنع/القوارب/الأسماك/الشحن: صور حقيقية مرخّصة Creative Commons / Public Domain تم جلبها عبر أداة البحث عن الصور (Pickpik, Pixnio, PublicDomainPictures, Rawpixel... إلخ).
- الفيديو: الفيديو التعريفي الذي رفعه المستخدم (`King_Fish_brand_introduction_video`).

## ما لم يُنفَّذ / يحتاج قرار من المالك
- **بيانات التواصل الحقيقية**: تم وضع عنوان/هاتف/بريد إلكتروني افتراضي (دمياط، مصر) — يجب استبدالها ببيانات الشركة الفعلية.
- **نموذج التواصل**: حاليًا تجريبي (عرض رسالة نجاح فقط دون إرسال فعلي). لتفعيله فعليًا يلزم إما:
  - ربطه بجدول بيانات (Table) لتخزين الطلبات، أو
  - ربطه بخدمة بريد/واتساب خارجية.
  أخبرني إن كنت تريد تفعيل أي من الخيارين.
- **رقم الهاتف/روابط التواصل الاجتماعي** داخل الفوتر والهيدر وهمية حاليًا (`#`).
- **منتجات/أرقام فعلية** (30 دولة، 15 ألف طن) هي أرقام تسويقية تقريبية — يُفضّل تأكيدها أو تعديلها من المالك.
- الموقع لم يُنشر بعد (Hosted Deploy) — هذا يتطلب تفويضًا صريحًا من المستخدم.

## النشر (Hosted Deploy)
لم يتم نشر الموقع بعد على رابط عام. عند الرغبة في النشر، أخبرني لأقوم بعملية Hosted Deploy رسمية (تتطلب موافقتك) ليصبح الموقع متاحًا عبر رابط مباشر.
